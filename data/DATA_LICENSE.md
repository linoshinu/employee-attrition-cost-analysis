The file in `raw/WA_Fn-UseC_-HR-Employee-Attrition.csv` is the IBM HR Analytics Employee Attrition & Performance sample dataset, mirrored on Kaggle by pavansubhasht. The Kaggle dataset page describes it as fictional data created by IBM data scientists and labels the database license **Open Database License (ODbL)**.

- License: [Open Database License v1.0](https://opendatacommons.org/licenses/odbl/1-0/).
- Size: 1,470 rows and 35 source columns.
- SHA-256 of the unmodified source file: `a5c31e38bd7fafc9bc333884eb181b06b41b8e5e488e8f7ccb27199fb3be7659`.

The source rows describe fictional people. They are not actual IBM employees or real employment events. The raw and derived databases are attributed to the source and remain subject to ODbL terms. The repository's MIT license applies to project code and documentation, not to the dataset.

The processed file removes constant administrative fields and adds derived labels and scenario-cost columns. It is provided under the same database terms as the source.
